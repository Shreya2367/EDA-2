## 📋 Executive Summary

This capstone presents a real-world credit risk challenge drawn from FinSight Bank, a mid-sized Indian retail and MSME lender. Students work with a 9-table relational dataset of 2 million loan records spanning 2010–2024, applying industry-standard EDA, feature engineering, and regression modelling to quantify credit default risk.
The dataset reflects actual banking data quality challenges: missing values, dirty records, class imbalance, multicollinearity, and macroeconomic regime shifts including the COVID-19 shock of 2020.

| Success Metric | Target |
| :--- | :--- |
| **AUC-ROC (default classifier)** | &ge; 0.82 (RBI / Basel III standard) |
| **RMSE — LGD regression** | &le; 8.0% (retail credit benchmark) |
| **Gini Coefficient** | &ge; 0.64 (minimum scorecard power) |
| **False Negative Rate** | &le; 15% (regulatory provisioning) |
